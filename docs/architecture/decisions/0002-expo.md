# 0002: Use Expo as the app framework

- Status: Accepted
- Date: 2026-11-02

## Context

Ton Up is an iOS app built by the same developer as Tippytoe, which is an Expo app with local builds. Reusing that setup (project layout, tooling, theming, i18n, StoreKit, build scripts) makes v1 much faster than starting a native Swift project.

## Decision

Build Ton Up with Expo (React Native) and TypeScript, using expo-router, structured like Tippytoe (`../tippytoe`). The v1 implementation plan fixes the exact libraries; by default they match Tippytoe's.

## Consequences

- v1 (tap-on-board and keypad input) needs no custom native code beyond what Tippytoe already uses.
- Camera scoring needs a custom native module (Expo Modules API) wrapping AVFoundation, Vision and Core ML, so the app runs as a development build rather than in Expo Go, as Tippytoe does for receipt scanning.
- Device linking (ADR 0008) also needs a native module for Network framework and Bonjour.
- Builds are local; no EAS cloud builds or over-the-air updates (ADR 0001).
- Android stays possible later but isn't a goal.
